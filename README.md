# 電化學實驗室 v1.1

繁體中文、免登入的國中電化學互動教具。以直接操作裝置觀察化學反應，支援電腦與平板瀏覽器。

## 主題與操作

- 鋅銅電池：接拆導線、鹽橋與電極，分辨外電路電子及鹽橋離子。
- 電解水：比較助導電條件、反接、氫氧體積比與虛擬氣體檢驗。
- 電解硫酸銅：切換碳／銅電極，比較正極產物、質量及濃度。
- 電鍍：觀察銅鍍層、兩極質量與缺少條件時停止的因果。
- 生活電池：六種電池的材料／通道結構、分類、充電／補燃料與回收。

可用點選或拖曳接線；電極及鹽橋可直接上下拖動。包含暫停、慢速／加速、投影模式、一鍵重設與短預測挑戰。沒有帳號、個資收集、分析追蹤或後端資料儲存。

## 本機啟動

安裝 Node.js 18 以上後：

```sh
git clone https://github.com/hikaruhen/electric-chemical.git
cd electric-chemical
npm start
```

開啟 `http://127.0.0.1:4173`。無第三方執行相依套件，無需 `npm install`。本機伺服器只監聽 loopback；若需更換埠號，可設定 `PORT` 環境變數。

## 驗證與 GitHub Pages

```sh
npm test
npm run check:release
npm run build
```

`release-files.json` 定義兩層白名單：Git 倉庫只納入核准來源、設定及小型模型測試；`_site/` 僅複製五個前端檔案，另外產生 `.nojekyll` 和含來源 SHA256／commit 的 `release.json`。README、測試與部署腳本不會進入網站成品。

GitHub Pages 使用 `.github/workflows/pages.yml`：在 `main` 更新或手動啟動時執行白名單檢查、模型測試、打包與部署。倉庫的 Pages Source 須設定為 **GitHub Actions**。工作流程採 [GitHub 官方 Pages 自訂工作流程](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)，動作固定到已核對的 commit SHA。權限僅部署工作需要的 `pages: write`／`id-token: write`，不更改倉庫可見性。

QA 畫面、教材檔案／渲染圖、UI 測試資料、本機交接紀錄、依賴與個人路徑均不發布。所有前端資源使用相對路徑，支援 Pages 的專案子路徑。

## 模型範圍

依指定國中自然教材的鋅銅電池、電流化學效應及生活電池範圍整理，教材檔案未包含在此倉庫。

- 鋅銅：兩杯各 50 mL、0.1 M 硫酸鹽，以 KNO₃ 鹽橋連通。Zn → Zn²⁺ + 2e⁻；Cu²⁺ + 2e⁻ → Cu。最多反應 0.005 mol；鋅負極氧化，銅正極還原。
- 電解水：水＋NaOH、理想碳電極。相同溫壓下 H₂:O₂＝2:1；60 示意秒對應 20/10 mL 觀察，不代表實際速率或水耗盡。虛擬氣體檢驗的 0.10 mL 門檻為示意，不是實驗安全量。
- 硫酸銅／電鍍：150 mL、0.2 M。負極析出銅；碳正極產生氧氣，銅正極則補回等量銅離子。Cu、Zn 摩爾質量分別為 63.546、65.38 g/mol。鐵作正極等未支援的副反應會明示停止。

粒子數、尺寸、速度、鍍層厚度與檢流計偏轉均為教學示意。未求解真實電流／電壓、過電位、極化、擴散、溫度或表面前處理。純水並非完全不導電，但本觀察尺度不顯示可測產氣。生活電池結構是材料與通道的示意，並非精密實物剖面或市售型號性能預測。

換電極／溶液／電解反接開始新觀察並清空舊產物；拆線、移出／浸回、鹽橋拆裝及暫停保留已生成的量。實體平板與教室投影效果仍需實機確認。
