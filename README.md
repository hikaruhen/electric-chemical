# 電化學實驗室

繁體中文、免登入的國中電化學互動教具，涵蓋五個教材主題：鋅銅電池、電解水、電解硫酸銅、電鍍，以及生活電池（碳鋅、鹼性、鉛蓄三種）。

- **本版來源**：`v2.3.1`（所有裝置預設暫停、按「▶ 播放」才開始反應；補充鉛蓄電池 3 負 2 正極板排列說明；承續 SO₄²⁻ 紫系與 NO₃⁻ 橙系離子配色、無預測挑戰、擬真中央零點檢流計與鉛蓄局部反應放大窗）。
- 正式站實際部署版本以網站的 [release.json](https://hikaruhen.github.io/electric-chemical/release.json) 為準，避免把本機來源或過往候選誤認為目前線上版本。

直接點選或拖曳接線與電極，即時觀察巨觀變化與微觀粒子。支援桌面、平板單屏操作與手機觸控瀏覽／縮放／拖曳模式切換，並提供原生全螢幕按鈕、暫停、速度切換、一鍵重設與讀值／氣體檢驗。無帳號、學生個資、分析追蹤或後端資料儲存。

## 執行與檢查

需要 Node.js 18 以上，沒有第三方執行相依套件。請透過本機 HTTP 伺服器啟動，不要以 `file://` 開啟 ES modules。

```sh
git clone https://github.com/hikaruhen/electric-chemical.git
cd electric-chemical
npm start
```

開啟 `http://127.0.0.1:4173`。本機伺服器只監聽 loopback，可透過 `PORT` 更換埠號。

```sh
npm test
npm run check:release
npm run build
```

發布沿用 `release-files.json` 的雙層白名單。倉庫只納入 15 個核准來源、README、設定及小型模型測試；Pages 成品只有五個前端檔（`index.html`、`style.css`、`app.js`、`model.js`、`battery-structure.js`）、`.nojekyll` 與含 SHA-256／commit 的 `release.json`。QA、教材、渲染圖、本機交接資料、協作報告及個人本機路徑均不發布。工作流程位於 `.github/workflows/pages.yml`，不改寫 Git 歷史或變更倉庫可見性。

## 現行操作與模型

- **裝置操作與跨裝置體驗**：平板橫向優先將主要裝置、常用控制與核心觀察同屏呈現，精確讀值與半反應按需開啟。手機預設保留頁面自然上下滑動與雙指縮放，並提供裝置放大／縮小／全圖、放大後平移，以及「拖曳裝置／恢復滑動」模式切換。
- **電極移出**：浸入狀態由電極位置、反應部位長度及實際液面推導。按鈕、本體點選、鍵盤與拖曳共用同一幾何；移出後與液面有明確空隙，導線保留，Esc 可取消拖曳或待接線。
- **檢流計、粒子、鹽橋與電流方向**：鋅銅電池以中央零點指針式檢流計示意電流偏轉方向（無校準安培刻度，斷路歸零）。外電路可切換「電子流 e⁻」「傳統電流 I」或隱藏；傳統電流以沿導線移動的帶桿箭頭表示方向（非物質粒子），與電子方向相反。鹽橋於有效反應期間持續分批補出 K⁺（入銅杯）與橙系 NO₃⁻（入鋅杯），與紫系 SO₄²⁻ 清楚區隔，舊批次留杯末段淡出、不瞬移回橋，最多保留 16 個示意粒子。
- **電解水**：倒置集氣管位於兩極上方；氣泡由浸液電極向上入管，無色氣體排開淡藍示意水（水本無色，淡藍僅為水位示意）。同溫壓體積生成比 H₂ : O₂＝2 : 1；Na⁺ 不析出鈉，OH⁻ 參與反應並維持電解質留存。提供虛擬氣體檢驗，氣體不足不假報成功。
- **停止與暫停**：全部裝置於首次進入、重設、切換主題返回或更換條件（電極／溶液／反接）後皆預設暫停，按「▶ 播放」才開始運作；切換返回保留已有產物與進度但不自動播放。按播放後，斷路、缺鹽橋、移出電極或未支援條件會依物理條件停止新反應（已生成氣泡仍可上浮收集），條件恢復即延續同一輪運作；暫停則所有動態凍結。換材料／溶液、反接或重設會清空本輪產物；拆線、移出與暫停保留已累積的量，停止態以「已增加／已減少」區分累積變化。
- **生活電池**：僅保留碳鋅、鹼性、鉛蓄三種。碳鋅為外層鋅筒負極、中央碳棒集流與二氧化錳正極材料；鹼性為中央鋅粉膠、負端集電棒、KOH 與外圈二氧化錳；鉛蓄展示 3 負 2 正、共 5 片交錯並聯的約 2 V 單格（負極板多一片，讓正極板兩面都對著負極板；含 4 片隔板與絕緣同極匯流排，並附 6 單格串聯約 12 V 說明），搭配局部反應放大窗呈放電負載／充電直流電源（正接正、負接負）與 H⁺、紫系 SO₄²⁻ 放充電定性動態，預設暫停、按「▶ 播放」開始，達示意終態即停止並可按「↺ 重置動畫」回到待播放狀態。一次電池只放電，不含虛擬電量、分類或回收任務。

## 理想化範圍與來源

教材範圍為指定國中自然 3 下（理化）備課 CH1 印刷頁 19–33；生活電池剖面依印刷頁 24–25 材料配置，採教材簡化平衡式，並核對 [OpenStax 電池章節](https://openstax.org/books/chemistry-atoms-first/pages/16-5-batteries-and-fuel-cells)、[GS 原廠鉛蓄充放電說明](https://www.gs-battery.com.tw/en/knowhow-technicalmanual-4.php)、[Bulldog 極板排列手冊](https://www.bulldog-battery.com/wp-content/uploads/Bulldog-Battery-Service-Manual-12122024.pdf)與 [Curtis 電池構造說明](https://www.curtisinstruments.com/evbatterymonitoring/)（2026-11-26）。各反應式原子與電荷平衡由 `tests/model.test.mjs` 檢查；鉛蓄充電為放電逆反應，正接正、負接負。

鋅銅各 50 mL、0.1 M；CuSO₄ 槽為 150 mL、0.2 M。Cu、Zn 莫耳質量分別為 63.546、65.38 g/mol。水電解在 60 示意秒生成 20 / 10 mL，以 3 示意秒運送延遲呈現上浮。時間、尺寸、粒子數、位移、鍍層與檢流計偏轉均為教學示意，並非真實反應速率。

本模型未求解實際電流／電壓、極化、擴散、溫度、碰撞力學或電鍍前處理；純水非完全不導電，但本尺度不顯示可測產氣。銅離子耗盡、同金屬、不匹配電極／溶液及鐵作正極等未支援條件皆明示停止，不外推反應。未模擬生活電池完整副反應與市售性能；實體手機、實體平板與教室投影仍須真機確認。
