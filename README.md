# 電化學實驗室 v2.0

繁體中文、免登入的國中互動教具：鋅銅電池、電解水、電解硫酸銅、電鍍，以及碳鋅／鹼性／鉛蓄電池。

直接點選或拖曳接線與電極，觀察巨觀變化及微觀粒子。提供暫停、速度切換、一鍵重設與投影模式；主畫面自然捲動，支援桌面及平板。沒有帳號、個資、分析追蹤或後端資料儲存。

## 執行與檢查

需要 Node.js 18 以上，沒有第三方執行相依套件。

```sh
git clone https://github.com/hikaruhen/electric-chemical.git
cd electric-chemical
npm start
```

開啟 `http://127.0.0.1:4173`。本機伺服器只監聽 loopback，可透過 `PORT` 更換埠號。

```sh
npm test
npm run check:release
npm run build
```

發布沿用 `release-files.json` 的雙層白名單。倉庫只納入核准來源、README、設定及小型模型測試；Pages 成品只有五個前端檔、`.nojekyll` 與含 SHA256／commit 的 `release.json`。QA、教材、渲染圖、本機交接資料、UI 大型測試及個人依賴路徑均不發布。工作流程位於 `.github/workflows/pages.yml`，不改寫 Git 歷史或改動倉庫可見性。

## 操作與模型

- **電極移出**：浸入狀態由電極位置、反應部位長度及實際液面推導。按鈕、本體點選、鍵盤與拖曳使用同一幾何；移出後反應部位與水面有清楚空隙。導線保留，Esc 取消拖動。
- **粒子反應**：有限的 Cu²⁺ 代表粒子抵達界面後轉為銅，留在電極；不跳回起點。Zn²⁺、銅正極補出的 Cu²⁺ 或碳正極生成的 H⁺ 依反應出現。硫酸根等離子保留。粒子數是示意，不是溶液內精確總數。
- **電解水**：倒置集氣管位於兩極上方。氣泡從浸液電極區自然上升入管；無色氣體逐步排開淡藍色水。水本為無色，淡藍僅是「水色示意」。同溫壓收集體積 H₂:O₂＝2:1；Na⁺ 不還原成鈉，OH⁻ 在正極消耗、負極生成，完成後兩種電解質離子仍保留。
- **停止與暫停**：斷路或移出停止新反應；已生成的氣泡仍可上浮集氣。暫停則反應、粒子及集氣全部凍結。反接、換材料／溶液或重設清空本輪產物；拆線與移出保留已生成的量。
- **生活電池**：只保留三種。碳鋅是外層鋅筒、中央碳棒及周圍二氧化錳糊；鹼性是外圈二氧化錳、中央鋅粉與負端集電棒；鉛蓄是交錯極板、隔板與硫酸液。點部位看短說明，反應式保持可見。一次電池只放電；鉛蓄可切換充放電。沒有虛擬電量、分類或回收任務。

## 理想化範圍與來源

教材範圍為指定國中自然印刷頁 19–33。生活電池剖面依第 24–25 頁材料配置；採教材簡化平衡式，並用 [OpenStax 的電池章節](https://openstax.org/books/chemistry-atoms-first/pages/16-5-batteries-and-fuel-cells)及 [GS 原廠充放電說明](https://www.gs-battery.com.tw/en/knowhow-technicalmanual-4.php)核對，日期 2026-11-13。方程式的各元素與電荷均由獨立測試檢查；鉛蓄充電為放電的逆反應，正接正、負接負。

鋅銅各 50 mL、0.1 M；CuSO₄ 槽為 150 mL、0.2 M。Cu、Zn 摩爾質量分別為 63.546、65.38 g/mol。水電解在 60 示意秒生成 20/10 mL；以 3 示意秒運送延遲呈現上浮，之後收集完畢。時間、尺寸、粒子密度、鍍層與檢流計偏轉均為示意，並非真實反應速率。

未求解實際電流／電壓、極化、擴散、溫度、碰撞力學或電鍍前處理；純水非完全不導電，但本尺度不顯示可測產氣。銅離子耗盡及鐵作正極等未支援條件會明示停止。未模擬生活電池的完整副反應與市售性能；實體平板及真實投影仍須實機確認。
